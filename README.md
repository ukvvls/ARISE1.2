# ARISE 1.2 — Fixed Crystal Liquid Glass

Static mobile-first Arabic/English financial dashboard. GitHub Pages deploys directly from the root.

## Changes
- Fixed glass transparency at a crystal-clear level; removed opacity slider.
- Added 15 accent colors that only tint glow and edge highlights.
- Added language toggle (Arabic/English) and in-app notifications panel.
- Refined water-like animated background and liquid shine.
- FX conversion uses Frankfurter reference rates; news uses GDELT. Market prices for equities/gold/oil remain unconnected and are clearly marked.

## Deploy
Upload all files to the repository root, except `.github/workflows/deploy.yml`, which must retain its path. GitHub Pages source: GitHub Actions.
